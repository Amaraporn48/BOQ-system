# ระบบจัดทำใบเสนอราคาและ BOQ กลาง (Quotation & BOQ Management System)

เว็บแอปพลิเคชันสำหรับจัดทำใบเสนอราคา (Quotation) และ BOQ (Bill of Quantities) ศูนย์กลางของบริษัท พัฒนาด้วย **Next.js 14 (App Router) + TypeScript + Tailwind CSS + Prisma ORM + SQLite (dev.db)** เพื่อทดแทนการทำงานผ่าน Excel จัดเก็บข้อมูลถาวรในฐานข้อมูล มีระบบจัดการเวอร์ชัน Revision ที่ไม่เขียนทับเอกสารเดิม และรองรับการพิมพ์/ส่งออก PDF ภาษาไทยอย่างเป็นทางการ

---

## 1. จุดเด่นและฟังก์ชันที่พัฒนาสำเร็จ (Implemented Features)

1. **ระบบเลขที่เอกสารต่อเนื่องอัตโนมัติ (Sequential Numbering)**
   - สร้างเลขที่อัตโนมัติจาก Backend เช่น `QT-2026-0001`, `BOQ-2026-0001`
   - ป้องกันเลขที่ซ้ำกันด้วย Atomic Transaction และไม่นำเลขที่ยกเลิกมาใช้ซ้ำ
2. **ระบบทำสำเนา vs ระบบสร้าง Revision (แยกกันชัดเจน 100%)**
   - **ทางเลือก A (Duplicate):** ทำสำเนาเป็นเอกสารใหม่ ได้รับเลขที่เอกสารใหม่ ไม่กระทบต้นฉบับ
   - **ทางเลือก B (New Revision):** ใช้เลขที่เอกสารหลักเดิม สร้าง Rev.00, Rev.01, Rev.02... โดยแต่ละ Revision เป็น Snapshot ข้อมูลถาวร ไม่มีการเขียนทับ
3. **ระบบเปรียบเทียบ Revision (Diff Breakdown Tool)**
   - เปรียบเทียบสอง Revision ในหน้าเดียว แสดงรายการที่เพิ่ม (+Added), รายการที่ตัดออก (-Removed), รายการที่แก้ไขราคา/ปริมาณ (Modified) พร้อมคำนวณผลต่างยอดเงินสุทธิ
4. **ตารางคำนวณ BOQ แบบ Excel ในเบราว์เซอร์**
   - จัดหมวดหมู่งาน (Categories) และรายการย่อย (Items)
   - คำนวณ จำนวน × ราคาต่อหน่วย อัตโนมัติ
   - คำนวณยอดรวมหมวด, ส่วนลด (% หรือ ฿), ภาษีมูลค่าเพิ่ม VAT 7%, และถอดภาษี (Inclusive/Exclusive)
   - แปลงตัวเลขเป็นตัวหนังสือภาษาไทย (BahtText) อัตโนมัติ
5. **ระบบป้องกันการบันทึกทับ (Optimistic Concurrency Locking)**
   - ใช้ฟิลด์ `version` ในฐานข้อมูล หากมีผู้ใช้เปิดหน้าจอค้างไว้และมีอีกคนบันทึกไปก่อน ระบบจะแจ้งเตือน Conflict ทันที ไม่เขียนทับข้อมูลอย่างเงียบ ๆ
6. **ระบบพิมพ์และส่งออก PDF มาตรฐานทางการ**
   - ออกแบบหัวจดหมายบริษัท เลขประจำตัวผู้เสียภาษี
   - ตารางรายการหลายหน้า รองรับภาษาไทยสมบูรณ์
   - ช่องลงนาม 4 ฝ่าย: ผู้จัดทำ, ผู้ตรวจสอบ, ผู้อนุมัติ, และลูกค้ารับราคา
   - ส่งออก PDF ของ Revision เก่าได้ตามข้อมูล Snapshot ฉบับนั้นจริง
7. **ระบบจัดการโครงการ สถานที่ และลูกค้า**
   - จัดการข้อมูลกลาง ไม่ต้องพิมพ์ซ้ำ
   - เพิ่มสถานที่ใหม่ได้ทันทีจากหน้า Editor ใบเสนอราคา โดยไม่ต้องสลับหน้า
8. **ระบบ Template มาตรฐาน**
   - มีเทมเพลตสำหรับงานแอร์ (HVAC), ไฟฟ้า (Electrical), ประปาและดับเพลิง (Plumbing & Fire), ปรับปรุงพื้นที่ (Fit-out)
9. **ระบบ Audit Log บันทึกทุกกิจกรรม**
   - บันทึกผู้สร้าง ผู้แก้ไข วันเวลา และเหตุการณ์สำคัญ
10. **ระบบสำรองข้อมูล (Database Backup)**
    - ส่งออกข้อมูลทั้งหมดของระบบเป็น JSON Backup ได้ในคลิกเดียวจากหน้า Settings

## 3. การติดตั้งและเริ่มใช้งานในเครื่อง (Local Setup)

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. ปรับโครงสร้างฐานข้อมูล SQLite
npx prisma db push

# 3. นำเข้าข้อมูลเริ่มต้น (ผู้ใช้, โครงการ, เอกสารตัวอย่าง Rev.00 & Rev.01, Template)
npm run db:seed

# 4. ทดสอบ Acceptance Criteria ทั้ง 12 ข้อ
node scripts/test-acceptance.mjs

# 5. รันเซิร์ฟเวอร์สำหรับใช้งานจริง
npm run build
npm start
# หรือรัน dev server: npm run dev
```

เปิดเว็บเบราว์เซอร์ไปที่: `http://localhost:3008` (หรือ Port ที่ตั้งค่าไว้)


## 5. การสำรองและกู้คืนข้อมูล (Backup & Disaster Recovery)

1. **ผ่านหน้าเว็บ UI:**
   - เข้าสู่ระบบด้วยบัญชี Admin
   - ไปที่เมนู **ตั้งค่าระบบและบริษัท** (`/settings`)
   - คลิกปุ่ม **"ดาวน์โหลดไฟล์สำรองข้อมูล (JSON Backup)"** ระบบจะส่งออกข้อมูลทุกตารางออกมาเป็นไฟล์ JSON
2. **ผ่านระดับไฟล์ (File-level Backup):**
   - คัดลอกไฟล์ `prisma/dev.db` ไปเก็บไว้ใน Cloud Storage หรือเครื่องสำรอง
3. **การกู้คืนข้อมูล (Restore):**
   - นำไฟล์ `dev.db` มาวางแทนที่ในโฟลเดอร์ `prisma/` หรือรัน `npm run db:seed` เพื่อเริ่มจากข้อมูลเริ่มต้นมาตรฐาน
